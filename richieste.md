# Richieste per le prossime app

Una riga per richiesta. `- [ ]` = da fare, `- [x]` = fatta (l'agente aggiunge `→ apps/<cartella>`).
L'agente prende sempre la **prima** riga aperta dall'alto. Puoi scrivere sia idee di app
("un timer per la pasta") sia indicazioni generali ("d'ora in poi preferisci app per la cucina").
Puoi aggiungere righe dal sito locale (sezione Richieste) oppure editando questo file su GitHub.
